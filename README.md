## Starnure

Minecraft plugins for **Paper & Folia**, made in Ukraine by Restarnure.

- Built for the latest versions (1.21.x - 26.x)
- Clean configs, in-game editors where it makes sense
- Fast support and regular updates

### Plugins

| Plugin | What it does | Get it |
|---|---|---|
| ToxicRain | Deadly toxic rain events that damage entities and transform the world | [BuiltByBit](https://builtbybit.com/resources/toxicrain-deadly-weather-for-minecraft.60769/), [Voxel Shop](https://voxel.shop/product/8824/toxicrain) |
| Relics SMP | Every player carries an ancient relic with a passive and two abilities | In development |
| Blindspot | Anti-xray, anti-freecam and anti-ESP: players only get what they could actually see | In development |
